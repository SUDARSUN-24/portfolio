Projects

All four are solo projects: I designed, built, tested and deployed each one.

Resonance

A voice studio that runs in the browser. Type any text, pick one of 7 voices and 45+ languages, and hear it with live captions. No install or account needed.

  • Eight tools on one site: read documents aloud, perform multi-voice stories, analyse your own voice, make beats and play speaking games.
  • Serverless back end on Netlify Functions and Blobs for the leaderboard, voice requests and a protected admin page.
  • 116 automated tests run before every deploy. A failing test blocks the release.
  • Installable, and works offline after the first visit.
Role
Solo: design, front end, back end, testing
Stack
HTML, CSS, JavaScript, Web Speech API, Web Audio API, Service Worker, Netlify Functions, Netlify Blobs, Node test runner

Velonix Customs

An interactive 3D vehicle showroom. Rotate five vehicles in the browser, customise one in the configurator and rev its engine.

  • One Three.js scene drives both the home page and the configurator. The camera moves to a new angle for each section as you scroll.
  • Configurator with paint, wheels, exterior, lighting, interior and power options, and a price that updates as you choose.
  • The engine sound is generated in code with the Web Audio API, one voice per cylinder, with no audio files.
  • Browser tests with Puppeteer.
Role
Solo: design, 3D, front end, testing
Stack
HTML, CSS, JavaScript, Three.js, Lenis, Web Audio API, Puppeteer, Vercel

About

I'm a student at Siam University in Bangkok. I learn by building complete projects and putting them online, from the first sketch to tests and deployment.

I like working close to the browser. Most of my projects use plain HTML, CSS and JavaScript with the browser's own APIs for speech, audio and 3D graphics, instead of large frameworks or paid services. That keeps them fast and free to host.

I care about the details users notice: pages that load quickly on a phone, work with a keyboard, respect reduced-motion settings and read clearly.
